# Platform icons

Local, build-time assets used to identify the parser's supported platforms. They are displayed for identification only and do not imply endorsement by the platform owners.

The favicon assets were retrieved on 2026-08-30 from public favicon endpoints for the corresponding official domains, then normalized to 128 × 128 lossless WebP. Soul, 梨视频, 皮皮搞笑, 绿洲, and 美拍 use their current Apple App Store artwork. 微信视频号 uses the Remix Icon `wechat-channels-fill` glyph because the platform hostname exposed an unrelated favicon. Remix Icon is used under the Remix Icon License v1.0; the license is included at `LICENSES/Remix-Icon-License-v1.0.txt`.
